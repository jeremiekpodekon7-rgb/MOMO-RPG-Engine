# MOMO RPG Engine

MOMO est un moteur de jeu Android Java orienté RPG fantasy isométrique, inspiré par les mécaniques de combat ATB + PA, d’ombres, de magie et de progression libre.

## Ce qui est inclus
- moteur d’affichage 2D isométrique
- génération procédurale de cartes
- entité joueur/ennemis
- système de bataille ATB + PA
- synthétiseur sonore 8-bit interne
- structure de base pour PNJ, quêtes, ville, donjons et ombres

## Lancement
1. Ouvrir le projet dans Android Studio.
2. Synchroniser Gradle.
3. Lancer l’application sur un émulateur ou un téléphone Android.

## Roadmap
- ajout d’UI de menu et d’inventaire
- simulation des classes guerrier/mage/archer
- système d’ombre, fusion, extraction
- quêtes PNJ + dialogue
- génération de plansètes et villes procédurales
- sauvegarde auto / multi-slot
- optimisation pour build APK release

## Notes
Cette version est une base moteur solide pour continuer le développement du jeu complet. Elle n’est pas un APK final premium, mais elle constitue le socle technique pour bâtir le projet de manière réaliste et évolutive.
